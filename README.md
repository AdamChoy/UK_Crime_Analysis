UK Crime Analysis

Author: Adam Choy

Date: 16th March 2026

Project Description

The analysis will draw on publicly available street-level crime data from data.police.uk, covering four police force areas across England. The dataset will span from February 2024 to January 2026, providing two full years of crime records for in depth analysis. At the conclusion of the Exploratory Data Analysis (EDA) report, two police force areas will be shortlisted for deeper investigation in a subsequent project.

How to recreate the analysis:

  1. Download UK crime dataset from Sharepoint

2. Download house price data and LSOA population data from Sharepoint

  3. Open the Pre-Processing notebook and run all cells

4. Open the EDA notebook and run all cells
